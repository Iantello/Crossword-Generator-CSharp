# Генератор Кроссвордов (C#)

![Language](https://img.shields.io/badge/language-C%23-blue)

Простой и эффективный генератор кроссвордов, написанный на C#. Проект использует алгоритм перебора для оптимального размещения списка слов на сетке заданного размера.
- **Тематика:** Компьютерная 🖥

## 🚀 Возможности

- **Динамическая генерация:** Создание валидных сеток кроссвордов из любого списка слов.
- **Настраиваемый размер:** Возможность задать любые размеры сетки (например, 15x15, 30x30).
- **Умный алгоритм:** Оптимизация пересечений слов и плотности заполнения.

## 📃 Как пользоваться

- Нажимаем "*Сгенерировать*", программа сгенерирует кроссворд.
- На экране появляются клетки с номерами и загадки.
- Вводим буквы в клетки. Управление осуществляется стрелками или курсором.
- Нажимаем "*Проверить*", программа подсвечивает правильные буквы зеленым, неправильные - красным.
